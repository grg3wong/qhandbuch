# Neue Zahlung erstellen
1. Titel definieren
   ![Pasted image 20260923224657.png](/img/user/0%20Bilder/Pasted%20image%2020260923224657.png)
2. Status auf "Freigegeben" setzen, damit die Zahlung später bei den Eltern und EZB aufscheint
   ![Pasted image 20260924124047.png](/img/user/Pasted%20image%2020260924124047.png)
3. Teilnehmer > Hinzufügen
   ![Pasted image 20260923224812.png](/img/user/0%20Bilder/Pasted%20image%2020260923224812.png)
4. zB nach Klassen filtern
   ![Pasted image 20260923225125.png](/img/user/0%20Bilder/Pasted%20image%2020260923225125.png)
5. alles auswählen und hinzufügen
   ![Pasted image 20260923225220.png](/img/user/0%20Bilder/Pasted%20image%2020260923225220.png)
6. Bestätigungsmeldung abwarten
   ![Pasted image 20260923225301.png](/img/user/0%20Bilder/Pasted%20image%2020260923225301.png)
7. (Alle auswählen) und Betrag zuweisen
   ![Pasted image 20260923225410.png](/img/user/0%20Bilder/Pasted%20image%2020260923225410.png)
8. Betrag eingeben und auf OK klicken
   (unterschiedlich hohe Beträge möglich)
   ![Pasted image 20260923225502.png](/img/user/0%20Bilder/Pasted%20image%2020260923225502.png)
9. Speichern und schließen
   ![Pasted image 20260923225536.png](/img/user/0%20Bilder/Pasted%20image%2020260923225536.png)
10. (alle) auswählen und informieren
   ![Pasted image 20260923225635.png](/img/user/0%20Bilder/Pasted%20image%2020260923225635.png)
11. rechts scrollbare Liste beachten
    ![Pasted image 20260923225811.png](/img/user/0%20Bilder/Pasted%20image%2020260923225811.png)
12. Informationstyp "edu.FLOW" wählen
    ![Pasted image 20260924124140.png](/img/user/Pasted%20image%2020260924124140.png)
13. Gleich informieren auf "Ja" setzen oder später aus edu.FLOW senden
14. "Über Zahlungen informieren", um Mailversand zu starten
15. Status einsehen
	- Offen = Zahlungsnachricht ungelesen
	- Initiiert = Zahlungsnachricht gelesen
	- Gezahlt![Pasted image 20260923185545.png](/img/user/0%20Bilder/Pasted%20image%2020260923185545.png)

> [!info] Doppelt überwiesen?
> Sekretariat wird informiert
> Rückzahlung muss eingeleitet werden
> oder Zahlung auf andere Forderung umbuchen
# Abrechnungsliste erstellen
Für Nachzahlungen bzw. Rückzahlungen
Differenz wird auf alle Teilnehmenden aufgeteilt
Ausgleichsposition wird automatisch vorbereitet
SCT-Sammler im Sekretariat für Rückzahlungen an ursprüngliche Zahlungsquelle
